# Narración con AI33/OpenSpeaker

AI33 es una alternativa de voz por API. Puedes escoger distintas voces del catálogo, no estás limitado a la voz de la demo. Generar puede consumir créditos del servicio; las tarifas, las voces disponibles y sus licencias dependen de tu cuenta y proveedor. AI33 es un servicio externo: al usarlo envías el guion al proveedor. No es la API oficial de ElevenLabs.

El cliente usa la API v3 de `https://api.ai33.pro`, con `xi-api-key` y solicitudes FormData. No requiere paquetes Python adicionales.

## 1. Configura tu propia clave

En PowerShell, esta opción evita escribir la clave en el comando y su historial:

```powershell
$claveAI33 = Read-Host 'Tu clave AI33' -AsSecureString
$env:AI33_API_KEY = [System.Net.NetworkCredential]::new('', $claveAI33).Password
```

En macOS/Linux, configura `AI33_API_KEY` mediante tu gestor de secretos o entorno privado. No pegues la clave en el guion, el código, una captura ni GitHub. El repositorio no contiene ninguna clave de ejemplo real.

## 2. Elige una voz

```bash
python herramientas/voz_ai33.py voces --proveedor elevenlabs --idioma Spanish
python herramientas/voz_ai33.py voces --proveedor minimax --idioma Spanish
```

También admite los proveedores `clone`, `edge`, `kokoro`, `vbee` y `fishaudio` cuando estén disponibles para tu cuenta. Usa el `voice_id` completo devuelto por el catálogo, incluyendo prefijo. Que un proveedor esté admitido por la API no garantiza que toda voz esté disponible o licenciada para cualquier uso.

## 3. Genera tu narración

Voz utilizada en la demo:

```bash
python herramientas/voz_ai33.py generar guion.txt salida/voz-ai33.mp3 --voz elevenlabs_7QXA3lh7d25G1SzsIJdv --velocidad 1
```

Para otra voz, cambia `--voz`. La velocidad documentada va de 0.5 a 1.5. Para hacer una prueba usa primero una frase corta; no repitas un guion completo solo para consultar el estado.

Por defecto se pide solo el audio. `--transcripcion` solicita además la transcripción de AI33 y puede añadir créditos y espera; para sincronizar el vídeo también puedes usar Whisper local.

El programa guarda un archivo `.ai33-task.json` junto a la salida y consulta la tarea hasta terminar. Si se interrumpe la espera, ejecuta **el mismo comando con los mismos parámetros y salida**: reanuda la tarea sin crear otra. Ante un fallo de conexión durante la creación, consulta el panel de AI33 antes de repetir, porque el servicio podría haber aceptado la solicitud. No borres el estado a ciegas.

La respuesta privada `.ai33-result.json` puede contener enlaces temporales de descarga. Estos archivos se excluyen de Git. La clave nunca se guarda en ellos ni se envía al servidor que aloja el audio.

## 4. Normaliza y vuelve a sincronizar

```bash
python herramientas/audio.py salida/voz-ai33.mp3 plantilla/public/voz-nueva.wav
```

Conserva primero la voz anterior y sustituye `plantilla/public/voz.wav` por la nueva. Después ejecuta `palabras.py` con ese audio y el guion definitivo. Revisa todos los cortes: cambiar de voz cambia la duración y la posición de las palabras. No basta con reemplazar el archivo conservando los tiempos viejos.

Para la composición `Demo`, sus recursos están separados en `plantilla/public/demo/`; la composición `Video` utiliza `plantilla/public/voz.wav`. Sigue la estructura del proyecto que estés editando.

Las voces remotas y Qwen local son alternativas. Para reproducir la demo ya incluida no necesitas clave, créditos ni un modelo: el audio final viene renderizado.
