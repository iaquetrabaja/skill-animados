# Portadas actuales

Las portadas muestran capturas reales de la demo de Animados. No contienen fotos del creador, rostros ni maquetas de móviles.

- `portada.png`: composición de tres escenas reales (huevo flotante, disolución y balanza), preparada para la tarjeta horizontal de Tools.
- `demo-poster.png`: captura vertical del vídeo para su reproductor.

Se obtienen del MP4 renderizado; no requieren un prompt de generación de imágenes. Las portadas fotográficas anteriores se han sustituido en las superficies activas.
